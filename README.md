# dotagents

Personal agent configuration and skills for AI coding assistants.

## Structure

- `AGENTS.md` — top-level agent instructions and conventions
- `skills/` — active agent skills
- `rules/` — reusable rules and patterns
- `disabled-skills/` — skills intentionally disabled

## Usage

These are my personal settings. Feel free to browse for inspiration, but they're tailored to my workflow and tooling.
